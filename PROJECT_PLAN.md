# Project Plan — Hotel Shivai

1. Plan: restaurant website with Home, About, Menu, Gallery and Contact.
2. Setup: HTML, SCSS, JavaScript and local images folder.
3. HTML: semantic header/nav/main/section/article/footer structure.

5. SCSS: variables, mixins, base, header and component partials.
6. JavaScript: mobile menu and contact-form validation.
7. Test: resize browser, keyboard-test navigation, validate form, check contrast and replace placeholder menu data with verified information.
